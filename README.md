# YETI DRIVE 0.7

Android-лаунчер для планшета в альбомной ориентации. Интерфейс использует
графитовую палитру, постоянную левую панель, карту по центру, погоду и плеер
справа, а также панель быстрого запуска установленных приложений.

## Сборка через GitHub Actions

После загрузки структуры проекта в корень репозитория откройте вкладку Actions.
Успешная сборка опубликует артефакт `YETI-DRIVE-debug-apk`.

## Конфигурация

- JDK 17
- Gradle 8.9
- Android Gradle Plugin 8.7.3
- Kotlin Android plugin 2.0.21
- compileSdk 35, minSdk 26, targetSdk 32

## Возможности

- Яндекс MapKit отображается в центральной области. Для загрузки карты задайте
  секрет `MAPKIT_API_KEY` в GitHub Actions или локально в `local.properties`.
- Погода загружается по выбранному пользователем городу через Open-Meteo;
  выбор города и последние координаты сохраняются на устройстве.
- В нижнюю панель можно добавлять любые приложения с экраном запуска,
  заменять и удалять ярлыки, менять их порядок. Настройки сохраняются локально.
- Системная строка Android/HarmonyOS остаётся видимой и показывает состояние
  сотовой сети, Wi-Fi, Bluetooth, геолокации, батареи и часов; дата отображается
  в верхней панели приложения.

Совместимость и поведение системной строки на конкретном Huawei MatePad SE с
HarmonyOS 3 нужно проверить на устройстве. Это приложение пока не назначается
системным Home launcher. Плеер остаётся быстрым переходом в Яндекс Музыку; чтение
MediaSession и отображение текущего трека не реализованы.

## Структура

- `settings.gradle` — репозитории плагинов и модуль app
- `build.gradle` — версии Gradle-плагинов
- `app/build.gradle` — настройки Android-приложения
- `app/src/main/` — Manifest и Kotlin-код
- `.github/workflows/android.yml` — CI-сборка APK
